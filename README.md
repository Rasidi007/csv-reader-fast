A fast drop-in replacement for make.fun's csv-reader 1.0.0: it parses broken CSV files several times faster while returning byte-identical answers on every case.

## Run it

```sh
MAKEFUN_INPUT_DIR=/path/to/cases MAKEFUN_OUTPUT_DIR=out node main.ts
```

It reads `cases.json` from the input directory and writes `answers.json` to the output directory.
